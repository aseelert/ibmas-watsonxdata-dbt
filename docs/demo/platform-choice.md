# Open source and IBM platform: an honest choice

The open-source route is excellent for learning and composable architecture:
dbt, Spark, Kafka/Flink, Airflow, OpenLineage/Marquez, OpenMetadata, and
Metabase each solve a focused problem. The trade-off is multiple deployments,
security models, upgrades, metadata contracts, and operational ownership.

watsonx.data supplies the open Iceberg lakehouse and engines. Adding watsonx.data
Integration (DataStage) and watsonx.data Intelligence (IKC, lineage, governance,
and data quality) reduces integration and governance fragmentation. They should
be demonstrated as complementary to open formats, not as a claim that every
open-source capability is included. Actual entitlement and licensing limits
must be confirmed against the applicable IBM License Information document.
