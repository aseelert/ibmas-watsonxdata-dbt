# 7. Catalog, governance, and data quality

OpenMetadata provides the open-source catalog demonstration: dbt artifacts,
tables, and Metabase lineage can be ingested into one UI.

```bash
bin/demo catalog
```

For an IBM production platform, use watsonx.data Intelligence / IBM Knowledge
Catalog for business terms, classification, relationships, quality rules, and
governed data products. DataStage is the stronger integration option where
managed connectors, operational ETL, and enterprise governance are required.
